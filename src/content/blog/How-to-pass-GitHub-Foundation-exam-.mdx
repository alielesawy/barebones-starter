# How to Pass the GitHub Foundation Exam

The GitHub Foundation exam is a comprehensive test designed to measure your knowledge and skills across various aspects of GitHub. This guide will help you navigate through the different domains, provide learning resources, and offer tips to prepare effectively. 🚀

## Objective Domains and Exam Percentage

* **Domain 1: Introduction to Git and GitHub** (22%)
* **Domain 2: Working with GitHub Repositories** (8%)
* **Domain 3: Collaboration Features** (30%)
* **Domain 4: Modern Development** (13%)
* **Domain 5: Project Management** (7%)
* **Domain 6: Privacy, Security, and Administration** (10%)
* **Domain 7: Benefits of the GitHub Community** (10%)

## Domain Breakdown and Key Concepts

### Domain 1: Introduction to Git and GitHub

* **Git and GitHub Basics**
  * Describe version control
    * Define distributed version control
      * Describe Git
        * Describe GitHub
          * Explain the difference between Git and GitHub
            * Describe a GitHub repository
              * Describe a commit
                * Describe branching
                  * Define a remote in Git terminology
                    * Describe the GitHub flow
                    * **GitHub Entities**
                      * Describe different GitHub accounts (personal, organization, enterprise)
                        * Explain GitHub’s products (free, pro, teams, enterprise)
                          * Describe deployment options for GitHub Enterprise
                            * Explain features in the user profile (metadata, achievements, profile readme, repositories, pinned repositories, stars)
                            * **GitHub Markdown**
                              * Identify the text formatting toolbar on comments
                                * Describe Markdown and its basic syntax
                                  * Explain where to find and use slash commands
                                  * **GitHub Desktop and Mobile**
                                    * Differentiate between GitHub Desktop and github.com
                                      * Describe available features with GitHub Desktop and Mobile
                                        * Manage notifications through the GitHub Mobile app
                                        Domain 2: Working with GitHub Repositories
                                        * Describe good README components and recommended repository files (LICENSE, CONTRIBUTING, CODEOWNERS)
                                        * Explain basic repository navigation and how to create a new repository
                                        * Describe repository templates and features for maintaining a repository
                                        * Explain how to clone a repository, create a new branch, add files, view insights, and save a repository with stars
                                        Domain 3: Collaboration Features
                                        * **Issues and Pull Requests**
                                          * Create and manage issues and pull requests
                                            * Describe the difference between issues, discussions, and pull requests
                                              * Explain how to link a PR to an issue and create a branch from an issue
                                                * Describe pull request statuses, code review options, and how to comment on code
                                                * **Discussions, Notifications, Gists, Wikis, and GitHub Pages**
                                                  * Differentiate between discussions and issues
                                                    * Manage notification subscriptions and filtering options
                                                      * Explain how to create and manage gists, wiki pages, and GitHub Pages
                                                      Domain 4: Modern Development
                                                      * **GitHub Actions**
                                                        * Describe GitHub Actions and where they can be used
                                                          * Explain how to find existing GitHub Actions
                                                          * **GitHub Copilot and Codespaces**
                                                            * Describe GitHub Copilot, its versions, and how to get started
                                                              * Explain GitHub Codespaces, its lifecycle, and customization options
                                                              Domain 5: Project Management
                                                              * **GitHub Projects**
                                                                * Describe GitHub Projects and their layout and configuration options
                                                                  * Explain the use of labels, milestones, and template repos
                                                                    * Explain how to create, edit, and delete saved replies and their benefits
                                                                      * Add assignees to issues and pull requests, and use project workflows
                                                                        * Describe project insights
                                                                        Domain 6: Privacy, Security, and Administration
                                                                        * **Authentication and Security**
                                                                          * Secure your account with 2FA
                                                                            * Describe access permissions and EMUs (Enterprise Managed Users)
                                                                            * **GitHub Administration**
                                                                              * Enable and disable features, recognize repository permission levels, and identify repository visibility options
                                                                                * Explain repository privacy settings, Security tab features, and managing collaborators
                                                                                Domain 7: Benefits of the GitHub Community
                                                                                * Describe the benefits of the open-source community and GitHub Sponsors
                                                                                * Explain how GitHub advances open-source projects and how to follow people and organizations
                                                                                * Describe the GitHub Marketplace, InnerSource, and forking
                                                                                * Explain the components of a discoverable repository and when to use issue and pull request templates
                                                                                Conclusion

                                                                                By understanding and mastering these domains, you will be well-prepared to pass the GitHub Foundation exam. Use the provided learning resources and practice exams to reinforce your knowledge. Good luck! 🍀
